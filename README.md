# CAT AURA 🐱

CAT AURA is a 2D arcade-style catching game developed using Python and Pygame. The player controls a cat to catch falling food items, collect Aura Score, avoid bombs, and survive through three increasingly difficult levels.

## Features

- 3 levels with increasing difficulty
- Aura Score system
- 3-life system
- Multiple falling food items and bombs
- Collision detection
- Pause and restart functions
- English and Bahasa Melayu interface
- Instructions screen
- Sound effects and background music
- Mission Passed and Mission Failed screens
- Object-Oriented Programming (OOP) structure

## Requirements

- Python 3
- Pygame

## Installation

Install Pygame:

```bash
pip install pygame

How to Run
Run the following command from the project folder:
python main.py

Controls
Key	Action
Left Arrow / A	Move Left
Right Arrow / D	Move Right
P	Pause / Resume
R	Restart Game
ESC	Return to Menu


Game Rules
- Catch food items to increase the Aura Score.
- Missing a good item reduces one life.
- Catching a bomb reduces one life.
- Avoiding a bomb is safe.
- The player starts with 3 lives.
- Complete all 3 levels to win.
- Each level lasts 20 seconds.
